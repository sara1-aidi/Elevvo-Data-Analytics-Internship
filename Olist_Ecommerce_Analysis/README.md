# Olist E-Commerce Customer Analytics

An end-to-end data analytics project exploring customer retention, cohort analysis, Customer Lifetime Value (CLV), delivery performance, and high-value customers using the Brazilian Olist E-Commerce dataset.

## Objectives

- Analyse customer retention through cohort analysis.
- Measure historical Customer Lifetime Value (CLV).
- Investigate delivery performance and review scores.
- Identify high-value customers and their revenue contribution.
- Build a star schema for business intelligence reporting.

## Tools & Technologies

- Python (Pandas, NumPy)
- SQL (SQLite)
- Matplotlib & Seaborn
- Power BI

## Project Structure

- `notebooks/` — Data analysis and cohort analysis.
- `sql/` — SQL queries and star schema.
- `data/` — Processed analytical datasets.
- `images/` — Analysis visualizations.
- `powerbi/` — Dashboard and screenshots.

## Dataset

Brazilian E-Commerce Public Dataset by Olist.

[Download from Kaggle](https://www.kaggle.com/datasets/olistbr/brazilian-ecommerce)

## Key Analyses

- Customer cohort retention
- Historical CLV and cumulative revenue
- Delivery time vs. review scores
- High-value customer analysis
